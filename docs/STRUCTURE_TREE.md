# 结构树识别方案（设计说明）

这份说明保存用户提出的结构树识别方案，供整板图生成之后的单元件识别使用；在计算量允许时，也可以用同一套逻辑贯穿扫描定位。它不是当前 Live 位姿匹配器的替换件。当前默认定位仍是 `TopologyExtractor` + `ConstellationMatcher`（焊盘 / 通孔 / 槽位的拓扑星座），那只是结构树的第一刀，还不是完整的元件-引脚-走线树。

面积外形记忆（扫描红区核对）和结构树是互补的，不是二选一：

- **面积 + 外形记忆**只判断「这块已拍覆盖在整板坐标系里长得合不合理」：总面积只能按一张新瓦片的量级增长，外形只能在已有红区上连通长出一块，超出正常边缘波动、突然多出孤岛或整块跳变，就视为误识别。它不能判断「这是哪个位置、哪一个元件」。
- **结构树**才负责身份：由元件外形、引脚、焊盘、走线、定位孔和相对位置组成可交叉验证的数据单元。生成整板总览之后，识别单个元件应使用这套逻辑；硬件算得过来时，扫描定位也可以全程使用。

## 1. 识别图要干净

借鉴二维码的思路，把画面先收成可识别的数字数据，而不是保存杂乱像素。

参与生成数据的，主要是二值形状：

- 正方形、长方形、圆形
- 线条
- 较大的统一色块

关注的对象是：

- 元件外形和引脚
- 焊盘、线路（走线）
- 定位孔
- 有用时也包括电路上的标注文本（丝印）
- 以及它们的形状大小和相对位置

可以忽略、不必写入识别图的：

- 细小的杂乱点
- 渐变、破碎、没有稳定外形的区域

这样识别图会更清爽，无用信息不保存。

## 2. 最小数据单元（一个元件，类似二维码）

极端情况下画面里只有一个元件。这时识别图就是：

- 该元件的外形
- 外形大小
- 它相对于焊盘、小通孔、线路、电路标注文本的相对位置

这些合在一起，组成一个像二维码一样的最小数据单元。

必须带有意识的容错：生成和匹配都不能太精准、太死板，否则识别时间会过长，或者稍有拍摄偏差就失败。要有一套科学合理的生成逻辑——阈值宽松到能吸收边缘波动和轻微透视/旋转，又收得住，不把无关杂点当成结构。

## 3. 组合单元与结构树（2 到 n 个元件）

视频中通常会有五、六个元件以上，因此会有多种组合：

- 1 个元件 → 最小数据单元
- 2 个邻近元件 → 两个单元的组合
- 3 个、4 个，直到 n 个 → 多个单元的组合

这些组合构成结构树。它们交叉互补识别：一个单元不确定时，用旁边单元的相对位置和外形来核对。组合越多，约束越多，准确率应上升，而不是错误率上升。按这个流程做下来，程序逻辑上不应再把没拍过的区域误认成已拍，或把 A 元件认成 B 元件；若仍出错，更可能是人工操作失误，而不是识别流程本身在「越拍越放松」。

## 4. 和红区面积外形记忆的分工

扫描过程中，每拍一张都在 **chain / 整板坐标系**（不是当前镜头画面）里记住全部红色覆盖的面积和外形。镜头一移动，当前画面里能看到的已拍区域本来就会变大变小，所以不能拿直播画面里的红区像素数直接比较。

面积外形门禁只回答：新的覆盖是不是「在旧覆盖上连通长出至多一张新画面」？它很快、很直接，适合作为多锚点校验之后的一层核对。

要回答「当前看到的是哪一块板区、哪一个元件」，仍需结构树。两块长得几乎一样的板区，面积外形过得了关，也仍然需要组合交叉验证才能判定；判定不了时应当拒绝，而不是猜。

## 5. 当前实现到哪一步，以后怎么升级

已落地、作为第一刀的部分：

- `TopologyExtractor` 抽出焊盘、通孔、槽位等拓扑点
- `ConstellationMatcher` 用这些点的星座做扫描定位
- 多锚点交叉校验、互不连通的大块红区不涂
- 链式坐标系下的红区面积 / 外形记忆门禁（本切片）

第一刀还不是完整结构树：还没有把元件外形、引脚、焊盘、走线、定位孔、丝印文字编成带容错的最小单元，也还没有 2..n 个元件的组合交叉验证，更没有把它接到默认 Live 匹配器上。

可导入模块 `src/vision/structure_tree.py` 已按上述数据模型写下形状基元、元件单元、组合节点和整板/视口快照，并带一个可测试的轻量抽取器：去掉细小杂点，把剩下的轮廓分成圆 / 矩形 / 类直线 / 大色块，并记录相对位置。它只证明模型可运行，**尚未**作为默认位姿匹配器接入 `StableCaptureSession` / Live 定位。

建议的后续升级路径（尚未实现，不在本切片承诺范围内）：

1. 把抽取器从「几何形状」推进到「元件 / 引脚 / 焊盘 / 走线 / 定位孔 / 丝印」分层标签，仍允许容差，不要求像素级死匹配。
2. 在单张画面里生成最小单元，再在邻近元件之间生成 2..n 组合，做成可查询的结构树快照，挂到瓦片或整板总览上。
3. 整板图生成之后，先用结构树做单元件识别与核对。
4. 计算量允许时，用同一套结构树辅助扫描定位：多组合交叉验证当前视口，和面积外形记忆一起工作；冲突时拒绝涂红或拒绝落盘，而不是取高分猜解。
5. 有了结构树约束后，再考虑回环闭合，抑制长距离扫描的接缝漂移。

以上路径需要单独设计和测试，不能把当前拓扑星座或面积外形门禁表述成「结构树已经完成」。
